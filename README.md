# 분쟁 대응 관리 프로그램

회사 앞 집회·분쟁 상황을 **여러 사람이 함께 기록하고 공유·대응**하기 위한 웹 앱입니다.
단톡방과 달리 모든 기록이 남고, 링크만 알면 어디서든(PC·모바일) 접속해 같은 화면을 봅니다.

## 주요 기능

| 기능 | 설명 |
|------|------|
| 🛡️ **대응 상황판** | 최근 상황·처리할 업무·통계를 한눈에 |
| 📋 **상황 일지 (타임라인)** | 집회/소음/충돌 등 사건을 시간순으로 기록, 사진·파일 첨부, 작성자 자동 기록 |
| ✅ **대응 업무 (칸반)** | 담당자·기한·우선순위로 할일 관리 (할일 → 진행 → 완료) |
| 📇 **연락처 · 관계자** | 경찰·구청·변호사·사내·상대측 연락처를 분류별로 정리 |
| 🗂️ **증거 · 자료함** | 사진·동영상·공문 업로드/보관/다운로드 |
| 🚨 **비상 알림** | 지정 대상에게 문자(SMS) 일괄 발송 + 발송 이력 기록 |
| 👤 **간단 로그인 / 사용자 관리** | 아이디·비밀번호 로그인, 관리자/일반 권한 |

## 빠른 시작

```bash
# 1. 패키지 설치
npm install

# 2. 환경설정 파일 준비 (필요시 값 수정)
cp .env.example .env

# 3. DB 초기화 + 기본 관리자 생성 (admin / 1234)
npm run init-db

# 4. 실행
npm start
```

브라우저에서 **http://localhost:3000** 접속 → `admin` / `1234` 로 로그인
→ 로그인 후 **우측 상단 이름 → 내 계정**에서 반드시 비밀번호를 변경하세요.

관리자를 직접 만들려면:
```bash
node scripts/create-admin.js 아이디 비밀번호 이름
```

## 여러 사람과 공유하기

이 앱은 하나의 서버에서 실행되며, 팀원은 그 주소로 접속합니다.

- **같은 사무실/네트워크**: 실행한 PC의 내부 IP로 접속 (예: `http://192.168.0.10:3000`)
- **외부에서도 접속**: 클라우드 서버(예: Render, Railway, 가정용 VPS 등)에 올리거나
  [ngrok](https://ngrok.com) 같은 터널로 임시 공개
- 사용자 계정은 **사용자 관리** 메뉴에서 팀원 수만큼 추가하면 됩니다.

> 데이터는 `data/` 폴더의 SQLite 파일에, 업로드 파일은 `uploads/` 폴더에 저장됩니다.
> 두 폴더를 백업하면 전체 데이터가 보존됩니다.

## 비상 알림(문자/카톡) 실제 발송 설정

기본값은 **기록 모드**입니다 — 실제 문자는 나가지 않고, "누구에게 무엇을 보냈는지" 기록만 남깁니다.
실제 SMS 발송을 켜려면 `.env` 를 수정하세요:

```env
NOTIFY_PROVIDER=solapi
NOTIFY_SENDER=01012345678        # 사전 등록된 발신번호
SOLAPI_API_KEY=발급받은_키
SOLAPI_API_SECRET=발급받은_시크릿
```

- 문자 발송은 [Solapi(구 CoolSMS)](https://solapi.com) 연동을 기본 제공합니다.
  (가입 → 발신번호 등록 → API 키 발급 → 위 값 입력)
- 카카오 알림톡, 네이버 SENS, 알리고 등 다른 서비스는
  `services/notify.js` 에 어댑터를 추가하면 붙일 수 있습니다.

> ⚠️ 실제 문자 발송은 건당 요금이 발생하며, 대량 발송 시 통신사/서비스 정책을 따릅니다.

## 폴더 구조

```
server.js            서버 진입점
db.js                SQLite 스키마·연결
auth.js              로그인/권한 미들웨어
routes/              페이지별 라우트 (timeline, tasks, contacts, files, alerts, users, auth, dashboard)
services/
  notify.js          비상 알림 발송 어댑터
  upload.js          파일 업로드 설정
views/               EJS 화면 템플릿
public/              CSS·JS 정적 파일
scripts/             init-db, create-admin
data/                SQLite DB (자동 생성, git 제외)
uploads/             업로드 파일 (자동 생성, git 제외)
```

## 기술 스택

Node.js · Express · SQLite(better-sqlite3) · EJS · express-session · multer
별도 DB 서버가 필요 없어 한 대의 서버에서 바로 실행·배포할 수 있습니다.
