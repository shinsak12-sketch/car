# 오프라인 급여계산 검증 프로그램 — 설계 스펙 (누적)

## 0. 개요
- **완전 오프라인 단일 HTML** (서버/인터넷 없음, 브라우저에서 파일 열어 동작)
- 데이터 소스 2종:
  - **폴더 연결 (고정/저빈도 변동)**: 연봉내역, 직원명부, 발령정보
  - **업로드 (매달 변동)**: (추후 백데이터 — 미정)
- 항상 **"대상 연월"** 기준으로 그 달 급여를 계산·검증

## 1. 데이터 파일

### 1-1. 연봉내역 (폴더, 확정 데이터 — 인사정보에서 긁어옴)
- 컬럼: No, 소속, 사번, 성명, 재직구분, **연봉일자**, 기본급, 실적급, 성과급, 성과가급, 변동역량1, 변동역량2, 연봉계, 역량등급, 종합등급, (종합등급중복)
- 연봉계 = 기본급+실적급+성과급+성과가급+변동역량1+변동역량2 (검증됨)
- **평가등급 무시** (이미 반영된 확정 연봉)
- 한 사번에 여러 계약행 가능 → **최신 연봉일자 계약 사용** (단, 임금피크·육아기단축은 특정일자 계약을 씀 — 아래)

### 1-2. 직원명부 (폴더)
- 쓰는 항목: **임금피크제적용여부(AB), 임금피크제예상일(AA)**, 사번(J) 조인
- 나머지 44개 컬럼은 미사용

### 1-3. 발령정보 (폴더, **연중 누적본** — 매달 전체 누적 제공)
- 2단 헤더(그룹 현재/발령전/발령후 + 세부)
- 쓰는 항목: **사번(B), 성명(C), 퇴직일(D), 발령구분(E), 발령시작일(F)**, (발령전/후 직무·직급은 14명 판별에 사용)
- 한 사번 다중 이력 → 시간순 재구성해 대상월 상태 판정

## 2. 기본 월급 산출
- 정상월: 월급여 = **각 연봉 항목 ÷ 12, 항목별 각각 원단위 절상** 후 합산
- 일할계산:
  - **1일급여(일당) = 연봉항목 ÷ 12 ÷ 30** (분모는 항상 30 고정)
  - **근무일수 = 실제 달력일수 기준** (그 달이 31일이면 31, 28/29일이면 그대로)
  - 그 달 급여 = **(1일급여 × 근무일수) → 마지막에 원단위 절상** (B방식)
### 일할 통합 모델 (대상월 안에서 급여형태가 바뀔 때만 적용, 월 전체 단일상태면 정상/전액 처리)
> 기준은 항상 30일. **앞 구간은 실제 달력일수로 세고, 마지막 구간 = 30 − 앞구간합.**
1. 총 기준일 = **30일 고정**
2. 대상월을 시간순 구간으로 분할 (발령/복직/입사 경계일 = 새 구간 시작일)
3. **마지막 구간 제외 앞 구간들 = 실제 달력 일수** (구간 시작~끝 inclusive)
4. **마지막 구간 일수 = 30 − (앞 구간 일수 합)**
5. 예외: 마지막 구간이 유급인데 결과 ≤0 → **1일로 보정**
6. 구간 지급률: 정상 100% / 무급 0% / 의병 80%(성과가급·변동역량1·2 제외) / 단축=새연봉 100%
7. 구간별 (연봉항목 ÷12÷30 × 구간일수 × 지급률) 합산 → **최종 원단위 절상**
- 검증 예시:
  - 1~10 무급 / 11~31 정상 → 무급10 + 정상20(=30−10)
  - 1~10 정상 / 11~31 의병 → 정상10(100%) + 의병20(80%)
  - 1~30 육아휴직 / 31 복직 → 근무 0→**1일** 보정
  - 육아휴직 중 5-14 복직 → 휴직13(1~13) + 근무**17**(=30−13)

## 3. 임금피크 검증
- 임금피크제적용여부='적용' 이고 대상월이 해당월(= 예상일의 월)일 때:
  - 연봉내역에 **연봉일자가 정확히 `대상연도-피크월-01`인 계약**이 있어야 함
  - 없으면 → **전체 연봉 계산 차단 + 알림** (누락 예방)
  - 있으면 그 삭감 연봉 그대로 사용

## 4. 발령구분별 급여 처리
| 발령구분 | 처리 |
|---|---|
| 퇴직 | **계산에서 완전 제외** (퇴직청산 별도, 잔여급여 포함 별도처리) |
| 육아휴직 | **무급** → 해당 달 걸치면 근무일수만 일할 |
| 무급휴직 | 무급 |
| 가족돌봄휴직 | 무급 |
| 난임휴직 | 무급 |
| 의병휴직 | **(급여 − 성과가급 − 변동역량1 − 변동역량2 − 고정역량가급) × 80%**. 부분월이면 근무일(100%)/휴직일(80%) 일할 분리 후 합산 |
| 육아기단축근로 | 연봉계약 체결 → 연봉내역 사용. **발령시작일자(=연봉일자) 연봉내역 없으면 → 전체 계산 차단 (임피 동일)** |
| 복직 | 복직일부터 지급 (일할) |

- **역량가급 = 변동역량1 + 변동역량2 (둘 다)**

### 4-1. 휴직 상태 판별 (발령데이터는 26년치뿐 → 과거 이월 휴직 보완)
- **명부 직무(P)에 `(휴직)` 표기** = 현재 휴직 상태 표식
- 판별:
  - 명부 직무=(휴직) 인데 26년 발령에 **휴직발령 없음** → 26년 이전부터 이미 휴직 (연초부터 계속 휴직으로 간주)
  - 26년 발령에 **복직발령만 있음** → 연초 전부터 휴직이었다가 복직 (복직일 전까지 휴직으로 간주)
- **미확인:** 이월 휴직(발령 없음)일 때 휴직 "종류"(무급/의병80%)를 어떻게 아는지 — 개발 전 확인

### 4-2. 휴직 연장 / 종류 변경 (발령 여러 개: 휴직>휴직>복직 등)
- 휴직>휴직 = 연장. 지급률 같으면 그대로.
- **종류가 바뀌며 지급률 변경 시 그 발령일부터 새 지급률** (예: 육아휴직 무급 → 의병휴직 80%)
- → 구간 분할 모델이 각 발령을 "지급률 가진 새 구간"으로 처리

## 5. 하드코딩 특이 케이스 (14명)
- 발령정보에서 **자동 판별** — 아래 조건 동시 충족:
  - 발령구분(E) = **`직무변경`**
  - 발령시작일(F) = **`2026-07-01`**
  - 직급 = **JA 계열** (직급코드 JA로 시작, 예 JA4/JA5)
  - 발령전 직무 = `소액전담` AND 발령후 직무 = `대물보상`
- 해당자 월급여에 **변동역량가급1 = 월 500,000원** 추가 (연봉내역에 없음)
- 알림: "N명 이렇게 처리됨" 표시
- (미확인) 500,000이 매달 지속인지/특정기간인지 — 개발 시 재확인

## 6. 확정 완료 로그
- (A) 역량가급 = 변동역량1 + 변동역량2 ✓
- (B) 일할: 일당 /30 고정, 앞구간 실제일수·마지막=30−앞, 유급마지막 최소1일 ✓
- (C) 의병휴직 부분월 → 구간 분리(100%/80%) 합산 ✓
- (D) 육아기단축 연봉 누락 → 전체 계산 차단 (임피 동일) ✓
- (E) 14명 → 발령정보 조건 자동판별 (직무변경/26-07-01/JA/소액전담→대물보상) ✓

## 8. 휴가 공제 (파일 4: 휴가 데이터, 폴더/누적)
- 사번(K) 조인, **일자별 분리 행**, 연중 누적, **결재진행상태=`결재완료`만 인정**
- 완전 무급(전액 공제): `가족돌봄휴가`, `보건(생리)휴가(무급)`, `무급휴가`
- 일부유급/일부무급 (앞쪽 유급 → 이후 무급 공제):
  | 구분값 계열 | 총 | 유급 | 무급 |
  |---|---|---|---|
  | 출산전후/출산전/출산후 | 90 | 60 | 30 |
  | 〃(미숙아) | 100 | 60 | 40 |
  | 〃(다태아) | 120 | 75 | 45 |
  | 유사산휴가(28주이상) | 90 | 60 | 30 |
- 유급/무급 경계 = **전체 출산휴가 시퀀스 누적**으로 판정 (달 넘겨 누적, 대상월 이전 소진분 반영). 같은 연도면 일자별 행을 합쳐서 카운트
- **출산전/출산후가 쪼개져 들어오는 케이스는 극히 드묾 → 자동처리 말고 담당자 확인 알림** (리스크 회피)
- 공제 공식 = **무급일수(R) × (연봉항목 ÷ 12 ÷ 30)**, 항목별 (연차·건강검진·특별휴가 등 유급은 공제 0)

## 9. 임금지급기 & 소급정산 (★ 계산 전체에 얹히는 레이어)
- 임금지급기: **매월 1일~말일** 급여를 **매월 20일 지급** (공휴일이면 앞선 근무일 선지급)
- 20일은 **선지급** → 지급일 이후(21일~말일) 발생한 변동은 그 달에 반영 못함
- 필요 기능: **당월 계산 시, 전월 20일 이후 발생한 급여 변동사항을 체킹해 이번달에 소급 처리**
- 회수(공제) 타이밍 2종:
  - 일반 변동(발령·무급휴가 등) → **다음달 소급 정산**(차액 가감)
  - **육아휴직 등 무급휴직**: 급여 자체가 안 나가므로 20일 이후 진입분 초과지급 → **복직 시 일괄 공제**
- (누적 발령/휴가 데이터를 다 갖고 있으므로 전월 실제 vs 기지급 차액 계산 가능)
- **확정:** ①당월도 20일 커트라인 적용(21일~말일 변동은 다음달로) / ②소급 차액은 부호대로 가감 / ③육아휴직류는 복직 발령월에 과거 초과분 일괄공제 / ④커트라인 = **실제 지급일**(20일이 공휴일이면 앞선 근무일로 선지급된 그 날짜)
- ⇒ **공휴일 캘린더 필요** (매월 실제 지급일 산출용). 데이터 소스/입력방식 개발 시 결정 (폴더 연결 or 내장 공휴일표)

## 10. 징계 (수기 입력 필드, 데이터파일 아님)
- 입력: 사번 / 성명 / 종류 (+감봉은 금액)
- **감봉**: 급여항목에 `감액` 항목 생성 → 입력금액 그대로 차감 (수기, 그 달치 직접 입력)
- **정직**: **(월급여 − 역량가급) × 50%** 지급. **임금지급기 단위 적용** (정직 N개월 = 발령일 이후 N회 지급분에 적용, 일할 분리 없음). 역량가급은 미지급(0)

## 11. 검증 범위/목적 (★ 최종 정의)
- **세전(gross) 금액 비교** 프로그램. 세금·4대보험 등 공제는 **대상 아님**(법정 기준, 추후 계획 없음)
- 목적: 프로그램이 계산한 세전 급여 vs 실제 세전 지급액을 비교해 **위 예외사항들의 문제/누락 판별**
- 알림(경고) 중심 산출물: 임피/육아기단축 연봉누락(차단), 출산휴가 분리행, 14명 처리, 소급정산 내역, 차이나는 인원 등

## 12. 고정역량가급 = 직책수당 (연봉에 없음, 명부 직책(O)으로 판정, 매월 고정액)
- 센터장 → 월 100,000
- 부서장 → 월 1,500,000
- 본부장 + 직급 L → 월 2,000,000
- 본부장 + 직급 이사 → 0
- 그 외 직책 → 0
- **부분월/휴직 시 직책수당도 일할** ✓
- **의병80%·정직50%의 "역량가급 제외"에 고정역량가급 포함** ✓ (제외 대상)
- 정직 = (급여 − 변동역량1 − 변동역량2 − 고정역량가급) × 50%

## 13. 매달 업로드 백데이터 (변동 항목)
- **연차수당**: 업로드(사번·금액), **매년 1월에만 지급**
- **생산성향상격려금**: 업로드(사번·금액)
- **기타**: 업로드(사번·**구분값**·금액) → 구분값이 급여대장 항목명과 매칭되어 인식 (상여금·차량유지비·조사연구비·업무성과금 등 커버)

## 14. 급여대장 (파일 6, 최종 비교대상, 업로드)
- 87컬럼. 세전 지급항목(T~AI)+총지급액(AJ)이 비교 구역. 과세분해/공제(AK~CI)는 범위 밖
- **지급유형(C)**: 한 사람 여러 행 가능하나 있으면 지급유형이 무조건 다름. **`급여`는 인당 1행**
- 퇴직급여 등 `급여` 외 지급유형 → 검증 제외(퇴직청산 별도)
- 항목 매핑(연봉→급여대장): 기본급→기본급(T) / 실적급→능력급(U)[**현재 미사용, 전원 0**] / 성과급→성과급(W) / 성과가급→성과가급(X) / 변동역량1→변동역량가급1(Y) / 변동역량2→변동역량가급2(Z)✓ / 직책수당→고정역량가급(AA) / 감봉→감액(AB)
- **소급정산은 급여대장에서 구분되지 않고 해당월 급여 행에 합산**되어 찍힘 → 우리 (①당월+②소급) 합계를 급여 행과 비교
- **완전일치 목적**: **우리가 가진(계산/업로드로 만든) 항목만** (계산값) vs (급여대장값) 1:1 비교, 조금이라도 다르면 전부 표시. 우리가 안 가진 급여대장 항목은 비교 안 함

## 15. UI/UX & 배포 결정
- **폴더 연결**: 사용자가 폴더 선택(브라우저) → 추후 경로 확정 시 상수 하드코딩으로 원클릭화. (file:// 보안상 완전자동은 제약 → webkitdirectory 폴더선택 방식)
- **파일 자동 인식**: 파일명 접두어 + **파일 내용(헤더 컬럼) 스니핑**으로 종류 자동 판별 → 한 폴더에 여러 파일 섞여 있어도 인식
- **이월 휴직**: 자동 감지(명부 직무=(휴직) & 발령 없음) → 리스트업 → 담당자가 **휴직시작일 + 휴직종류(드롭다운)** 수기 입력
- **14명 +50만원**: 해당 직무(대물보상)·직급(JA) **상태 유지되는 한 계속** 적용
- **디자인**: 좌우 2분할, 카드/블록/버튼, 음영·입체·모션 효과, 라이트/다크 토글, 완숙한 앱 느낌, 매우 직관적
- **엑셀 다운로드**: 최종 결과 + 예외처리 항목 리스트 + 점검필요 체크 포함
