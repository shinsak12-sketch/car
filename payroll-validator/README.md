# 급여검증 · 오프라인 급여계산 검증 프로그램

인터넷·서버 없이 **브라우저에서 `index.html`만 열면** 동작하는 세전(gross) 급여 검증 도구입니다.
기준 데이터(연봉·명부·발령·휴가·공휴일)를 폴더에서 끌어오고, 실제 지급된 **급여대장**과
**항목별 완전일치**를 비교해 문제·누락을 찾아냅니다.

## 실행 방법 (2단계 흐름)
1. **Chrome 또는 Edge**로 `index.html`을 엽니다. (폴더 선택 기능은 Chromium 계열 지원)
2. **① 기준 데이터 폴더** → `폴더 선택` → 연봉/명부/발령/휴가/공휴일 엑셀이 든 폴더 지정
3. 필요 시 **② 변동항목**(연차수당·생산성향상격려금·기타), **③ 징계**, **④ 이월 휴직** 입력
4. 상단 **대상 연월** 선택
5. **[A] 급여 계산 실행** → 전 직원 급여명세가 **새 창(리스트)**으로 열림
   - 비고에 특이사항(일할 사유·일수, 임금피크, 14명 특례, 무급휴가 공제, 소급 등) 표시
   - `급여명세 엑셀` 저장 / 새 창에서 인쇄·PDF 가능
6. (마지막) **[B] 급여대장 업로드 → 검증 실행** → 계산값과 대장을 세전 항목별로 대조,
   **검증 결과 새 창**에 일치/불일치 + 비고(특이·불일치 항목) 표시, `검증결과 엑셀` 저장

> 급여계산은 **급여대장 없이** 됩니다. 급여대장은 마지막 검증 단계에서만 필요합니다.

## 파일 자동 인식
파일명이 아니라 **파일 내용(헤더 컬럼)** 으로 종류를 판별합니다.
따라서 폴더에 여러 파일을 그냥 넣어두면 파일명이 무엇이든 자동으로 인식합니다.
(연봉일자·연봉계 → 연봉, 임금피크제적용여부 → 명부, 발령구분 → 발령, 휴가종류 → 휴가,
귀속년월·총지급액 → 급여대장, 날짜목록 → 공휴일)

## 데이터 파일
| 파일 | 소스 | 사용 항목 |
|---|---|---|
| 연봉내역 | 폴더 | 확정 연봉(최신 연봉일자), 6개 급여항목 |
| 직원명부 | 폴더 | 임금피크(적용/예상일), 직책(직책수당), 직무((휴직)판별) |
| 발령정보(누적) | 폴더 | 퇴직·휴직·복직·단축·직무변경 |
| 휴가(누적) | 폴더 | 무급휴가 공제(결재완료만) |
| 공휴일 | 폴더 | 실제 지급일 산출 |
| 급여대장 | 업로드 | 검증 대상(세전) |

## 계산 규칙 요약
- **정상월**: 각 연봉항목 ÷ 12, 항목별 원단위 절상 후 합산
- **일할**: 일당 = 연봉항목 ÷ 12 ÷ **30**, 근무일은 30일 모델
  (앞 구간 실제일수, 마지막 구간 = 30 − 앞구간합, 유급 마지막 최소 1일) → 마지막 절상
- **임금피크**: 해당월(피크월)에 `연봉일자 = 연도-피크월-01` 계약 없으면 **전체 계산 차단**
- **육아기단축**: 발령시작일자 연봉 없으면 **전체 계산 차단**, 있으면 그 계약으로 일할
- **발령**: 퇴직=제외 / 육아·무급·가족돌봄·난임휴직=무급 /
  의병휴직=(급여 − 성과가급 − 변동역량1·2 − 고정역량가급) × 80% / 복직=복직일부터 일할
- **휴가**: 가족돌봄·보건(생리)무급·무급휴가 = 전액 공제,
  출산 계열 = 앞 60일(다태아 75) 유급·이후 무급(누적), 출산전/후 분리행은 담당자 확인 알림
- **직책수당(고정역량가급)**: 센터장 10만 / 부서장 150만 / 본부장+직급L 200만 / 본부장+이사 0 (일할)
- **직무변경 특례(14명)**: 26-07-01 직무변경 · JA · 소액전담→대물보상 → 변동역량가급1 +50만(상태 유지 시 계속)
- **징계**: 감봉 = `감액` 차감(수기 금액) / 정직 = (급여 − 역량가급 − 고정역량가급) × 50%
- **임금지급기**: 매월 1일~말일 급여를 20일 지급(공휴일 앞선 근무일). 지급일 이후 변동은 다음달 소급,
  육아휴직 등 무급은 복직월 일괄 공제

## 검증
- 급여대장 `지급유형 = 급여` 행(인당 1개)만 대상, 퇴직급여 등은 제외
- **우리가 계산/보유한 항목만** 1:1 비교, **1원이라도 다르면 전부 표시**

## 구조 (오프라인)
```
payroll-validator/
├─ index.html          # 앱
├─ styles.css          # 디자인(라이트/다크)
├─ js/
│  ├─ recognize.js     # 파일 인식·파싱
│  ├─ engine.js        # 계산 엔진
│  └─ app.js           # UI·엑셀 export
└─ vendor/
   └─ xlsx.full.min.js # SheetJS (엑셀 파싱, 오프라인 내장)
```

## 추후
폴더 경로가 확정되면 `app.js`의 폴더 선택부를 고정 경로로 바꿔 원클릭 연결 가능
(브라우저 보안상 완전 자동 로드는 로컬 서버(localhost)에서 File System Access API로 확장).
