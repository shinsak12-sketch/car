# 사택 관리 시스템 (오프라인 프로토타입)

보안망 내 **완전 오프라인** 환경에서 동작하는 총무 담당자용 단일 HTML 프로그램입니다.
서버 없이 크롬/엣지에서 `index.html` 을 더블클릭해 바로 실행합니다.

## 실행 방법
1. `index.html` 을 크롬 또는 엣지로 엽니다. (파일 더블클릭)
2. 상단 우측 **데이터 폴더 선택** → 데이터를 저장할 폴더를 지정합니다.
3. 지정 폴더에 `sasys_data.json` 이 자동 생성되고, 모든 변경이 즉시 저장(축적)됩니다.
4. 다음 실행 시 이전 폴더가 자동 복원됩니다. (권한 만료 시 재선택 안내)

> 최초 실행 시 폴더를 지정하기 전에는 **샘플 데이터**가 화면 확인용으로 표시됩니다.
> 폴더를 지정하면 해당 폴더의 파일 내용으로 전환됩니다(비어 있으면 샘플이 기록됩니다).

## 데이터 저장
- **File System Access API** 사용 — 지정 폴더의 `sasys_data.json` 에 즉시 읽기/쓰기.
- 폴더 핸들은 IndexedDB 에 보관되어 재실행 시 복원됩니다.
- 미지원 브라우저(예: 구형/파이어폭스)에서는 **브라우저 로컬 저장(localStorage)** 으로 자동 폴백되며,
  화면 상단에 안내가 표시됩니다. 이 경우 **데이터 탭 → JSON 내보내기**로 정기 백업을 권장합니다.
- 별도 **JSON 내보내기/가져오기** 백업 버튼(데이터 탭)을 제공합니다.
- 첨부파일 저장 없음 — 텍스트 데이터만 관리합니다.

## PDF 자동 파싱 (선택)
결재 PDF → 계약 데이터 자동 추출 기능은 **pdf.js** 를 사용합니다.
완전 오프라인 유지를 위해 CDN 대신 **로컬 번들**을 권장합니다.

- 이 폴더에 `pdf.min.js` 와 `pdf.worker.min.js` 두 파일을 함께 두면 자동 PDF 파싱이 활성화됩니다.
  (Mozilla pdf.js 배포본 `pdf.min.js`, `pdf.worker.min.js` 를 보안망 반입 후 이 폴더에 복사)
- 두 파일이 없으면 자동 파싱 대신 **대체안**이 제공됩니다:
  신규 계약 등록 화면에서 **PDF 대신 텍스트 붙여넣기** → PDF 뷰어에서 텍스트를 복사해 붙여넣으면
  동일한 라벨 파서로 필드가 채워집니다. (또는 폼에 직접 입력)

### 파싱 대상 라벨(고정 양식)
`센터명, 성명, 사번, 연고지 주소, 사택 주소, 계약구분(전/월세), 사용층, 전용면적,
소유주, 보증금 지급금액, 월세 지급금액, 월세 지급일, 문서번호, 결재선 마지막 결재일(→ 결재완료일)`

파싱 결과는 **즉시 저장되지 않고** 검토/수정 폼에 채워져 보여지며, 담당자 확인 후 저장됩니다.
파싱 실패 필드는 빈칸으로 두고 수동 입력할 수 있습니다.

## 화면 구성(탭)
1. **대시보드** — 전체/입주중/공실, 이번달 총월세, 만료임박(60일), 정산 미완료, 미종결 이슈
2. **사택 대장** — property 리스트 → 계약·이슈 타임라인
3. **계약 관리** — 신규(PDF 업로드)/수정/해지
4. **퇴실 정산** — 6개 항목 체크리스트(강제), 미완료 목록
5. **이슈 관리** — 접수/진행/종결 트래킹
6. **재배정** — 공실 물건에 새 계약 배정
7. **한도 기준** — 지역·직급 한도표 편집
8. **데이터** — 폴더 지정, 백업/복구, 변경이력

## 데이터 모델(5계층)
`property → contract → settlement` / `issue` / `changelog(자동기록)`
자세한 필드는 `index.html` 상단 주석 및 `[STATE]` 섹션 참고.

## 참고
- 지역·직급 한도표는 프로토타입에서 **지역 기준**으로 판정하며, 직급 열을 추가해 세분화 확장이 가능합니다.
- 계약 수정 시 전/후 값이 `changelog` 에 자동 기록됩니다(필수 요건).
- 한도 초과 시 빨간 플래그가 표시되고 **초과 사유 입력이 강제**됩니다.
